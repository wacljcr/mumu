### 8.0.39 · 2026-11-05

**终于把「录视频」做进来了：全屏录、局部录，停止键在自己手里。** 这是 8.0.20 之后 19 个版本的合并发布，中间版本都没对外发，只发这一个。

- **新增录屏（全屏 / 局部）** — 截图面板底部多了录制按钮，悬浮球菜单里也有入口。局部录制是先框一块区域再开录，停止后自动裁剪到框选范围，不会把整屏都留下
- **录制范围看得见** — 局部录制时选区保持原亮度、其余区域压暗，录的是哪一块一眼就知道
- **【■ 停止】一键停** — 屏幕右上角常驻红色停止按钮。之前试过让用户点系统状态栏那个红点，但 QQ / 游戏这类全屏 App 里状态栏被藏起来，那个点根本按不到，录制停不下来、最后只能从控制中心停成整屏；现在所有场景都用自己的按钮，点一下直接停止并保存
- **系统红点自动隐藏** — 录制时状态栏那个系统自带红胶囊会被自动藏掉，屏幕上只留一个停止入口，不会两套并存看着乱
- **息屏自动停止** — 锁屏 / 息屏时自动结束录制，不会录出一堆黑屏
- **手势支持 2/3/4/5 指** — 自定义手势除了认形状，还认手指数量：2 指画的圈和 4 指画的圈不会互相触发，打游戏不容易误碰；「多指上滑」那套触发方式已移除
- **手势画板放大** — 录制手势的画布撑到接近满屏，四指五指也张得开、画得下
- **局部截图画面冻结** — 框选、拖动、缩放全程画面静止，所见即所得
- **OCR 改进** — 识别速度明显提升；新增 Google Cloud Vision、OCR.Space、通义千问 OCR 几个云端引擎可选，系统识别依然免费、离线可用
- **iOS 17 适配** — 修 iOS 17 上的抓屏与识别问题，不影响 iOS 16 用户
- **设置面板瘦身** — 删掉重复的说明大段、分组说明压成一句、大模型相关选项收进可折叠分组，翻起来短很多

### 8.0.19 · 2026-10-27

**重做后的首发稳定版。** 之前 7.x 有一批版本装上去会黑屏 / 循环重启，已全部停止分发；8.0 从原始源码重做，一路修到翻译可用，这版才发出来。

- **设置面板内置完整说明** — 最底部「关于 → 使用方法（点击查看）」，可滚动、可长按复制
- **彻底移除设备授权** — 不再需要 UDID、不需要激活码，装好即全功能
- **取消「工作模式」** — 两种翻译都要先识别文字，没必要把面板分成两套；改为「翻译引擎（系统 / 百度）」与「识别引擎（系统 / 大模型 / PaddleOCR）」两个独立滑动选择，想要什么就选什么
- **面板重排** — 80 项精简到 67 项，从上往下按「开关 → 翻译 → 识别 → 大模型（可选）→ 截图与工具栏 → …」排列，一路填完就能用
- **识别语言不再写死** — 之前只加载简体中文与英文模型，截日文 / 韩文 / 繁体 / 俄文会一个字都读不出；现在取系统支持的全部语言并自动检测语种
- **翻译十几秒的问题** — 翻译前改成走设备端识别（0.2~1 秒、离线），不再先上传图片等大模型推理
- **画图「完成」没复制成功** — 剪贴板写入改为带回读校验，失败会提示并可重试，且不会关掉你正在画的图
- **翻译面板与工具栏重叠** — 系统翻译界面改由独立高层浮窗承载，工具栏被完全盖住，关掉翻译也不会回到工具栏
- **从旧版升级** — 模型库 Key、百度翻译密钥、工具栏排序、翻译 / 识别引擎选择都会自动迁移，历史截图与自定义机框目录也一起搬过去，不用重填
