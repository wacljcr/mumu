### 8.0.19 · 2026-10-27

**重做后的首发稳定版。** 之前 7.x 有一批版本装上去会黑屏 / 循环重启，已全部停止分发；8.0 从原始源码重做，一路修到翻译可用，这版才发出来。

- **设置面板内置完整说明** — 最底部「关于 → 使用方法（点击查看）」，可滚动、可长按复制
- **彻底移除设备授权** — 不再需要 UDID、不需要激活码，装好即全功能
- **取消「工作模式」** — 两种翻译都要先识别文字，没必要把面板分成两套；改为「翻译引擎（系统 / 百度）」与「识别引擎（系统 / 大模型 / PaddleOCR）」两个独立滑动选择，想要什么就选什么
- **面板重排** — 80 项精简到 67 项，从上往下按「开关 → 翻译 → 识别 → 大模型（可选）→ 截图与工具栏 → …」排列，一路填完就能用
- **识别语言不再写死** — 之前只加载简体中文与英文模型，截日文 / 韩文 / 繁体 / 俄文会一个字都读不出；现在取系统支持的全部语言并自动检测语种
- **翻译十几秒的问题** — 翻译前改成走设备端识别（0.2~1 秒、离线），不再先上传图片等大模型推理
- **画图「完成」没复制成功** — 剪贴板写入改为带回读校验，失败会提示并可重试，且不会关掉你正在画的图
- **翻译面板与工具栏重叠** — 系统翻译界面改由独立高层浮窗承载，工具栏被完全盖住，关掉翻译也不会回到工具栏
- **从旧版升级** — 模型库 Key、百度翻译密钥、工具栏排序、翻译 / 识别引擎选择都会自动迁移，历史截图与自定义机框目录也一起搬过去，不用重填
