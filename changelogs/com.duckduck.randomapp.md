# 随机时间打开app（com.duckduck.randomapp）

### 1.0.0 · 2026-11-24

首发上源。

- 设定时间段，到点在区间内随机时刻打开所选 App（多选则依次全部打开）
- 生效日：每天 / 每周指定星期 / 排除某天，非开启日不触发
- 打开 URL：到点打开 App 后依次打开配置的 URL，可直达钉钉打卡页面
- 重复打开：每个时间段内按设定间隔重复
- 设置面板：全量已安装 App + 图标 + 已选置顶、搜索、立即测试、诊断日志一键复制

> 支持 iOS 15.0+ rootless 越狱（Relaxin / RootHide / Dopamine），依赖 mobilesubstrate 或 ellekit、preferenceloader。
