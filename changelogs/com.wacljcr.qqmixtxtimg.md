# QQ图文同发（com.wacljcr.qqmixtxtimg）

### 1.2 · 2026-10-31

**修掉两个从 1.1.13 起就存在的硬伤：相册图发不出去、照片带不上文字。**

- **修复「相册选照片/视频，点发送没反应、发不出去」** — 根因是旧版为把文字塞进媒体消息，在相册发送入口改写了这个方法的入参（`sendText`）。它不是"可选配文"，而是媒体发送的必要参数，被改写后 QQ 拿不到，整条媒体直接不发（照片、视频都一样，只能干看着点不动）。现已**彻底移除该入口改写**，图片/视频全部交回 QQ 原生发送
- **修复「从相册发照片，输入框里的字没跟上去」** — 旧版取字依赖时间窗口（发送瞬间 10 秒 / 快照 20 秒）。从相册挑图、挑视频本身就要花时间，挑完再点发送时窗口早过期，于是静默放弃合并。现改为**点发送的瞬间实时读输入框**，不再受任何时间窗口限制，挑多久都不影响
- **收敛为三种稳定玩法** — 相册照片、收藏表情包、QQ 自带大表情：打字后发送，文字自动并入同一条消息。相册视频按 QQ 原生发送、插件不做任何干预，确保视频一定能发出去
- **下线诊断信息打屏** — 排查期那个三行小字诊断框已删除，恢复 1.8 秒轻提示，并按场景区分文案：`✓ 文字已随图片发出` / `✓ 文字已随表情发出`
- **本机回显限制不变** — 自己手机上刚发出的那条，仍**需要返回聊天列表再进入会话**才能看到文字（QQ 9.3.70 的气泡由它自己的 Swift 管线在点击发送瞬间一次性构建，插件层拿不到那个入口）；**对方手机 / 电脑端是即时可见的**，轻提示可即时确认
- 版本 1.1.13 → 1.2

### 1.1.13 · 2026-10-30

**修掉"没打字发表情也弹提示"的误报 + 修复实验版递归闪退。**

- **修复误弹提示** — 用户反馈"只要发表情就出现『文字随表情包发出』，没输入文字也有提示"。根因是文字快照长缓存残留：删字/清空后没失效，残留被当"刚打的字"注入并弹提示。现已改为**发送瞬间实时采样输入框 + 收紧时间窗口**（实时 10 秒 + 快照 20 秒，替代原先 5 分钟长缓存），空输入绝不再弹提示、也不会把旧文字误带进表情消息
- **修复递归闪退** — 撤回上一测试版为做"本机即时显示"而对内核事件分发点（onAddSendMsg:）的全量 hook：该点命中 QQ 多播分发器，触发无限递归打穿栈保护（SIGBUS 闪退）。现已移除，运行稳定
- **防双发 / 防误带** — 发送入口、消息记录、NT 落库三层注入均带结构校验与"已注入"守卫，QQ 内部对消息模型变更时自动退避，不影响正常收发
- **本机显示限制已坐实** — 经对落库层 / 内核通知总线 / Swift 渲染管线多轮逆向，确认 QQ 9.3.70 聊天气泡由 Swift 管线在点击发送瞬间一次性构建，插件层无法干预。维持"退出重进会话后本机可见、对方/电脑端即时可见"现状，发送轻提示可即时确认
- 版本 1.1.11 → 1.1.13

### 1.1.11 · 2026-10-30

**稳定性加固 + 本地回显机制攻坚收官。**

- **修复本地回显实验引入的崩溃隐患** — 中间实验版本曾把未包装的消息元素直接塞进消息记录，导致对元素调方法时无法识别而闪退；现已在所有注入路径统一套上 QQ 自己的元素包装层，并增加类名守卫：遇到非预期结构自动跳过注入、原样透传，绝不硬来
- **发送链路多层防御** — 发送入口、消息记录两条路径的注入均带结构校验，QQ 内部对消息模型的包装变更时自动退避，不影响正常收发
- **本地回显结论** — 经对消息落库层、内核通知总线、Swift 渲染管线的多轮逆向确认：QQ 9.3.70 聊天气泡内容由 Swift 内部管线在点击发送瞬间一次性构建，插件层无法干预。因此本机发送瞬间看不到文字属 QQ NT 架构限制，**对方手机、电脑端、退出重进会话后均正常显示**，发送轻提示可即时确认文字已发出

### 1.1.5 · 2026-10-30

**表情包模式全面打通 + 稳定性修复。**

- **修复表情包模式闪退** — 根治了构造消息元素的引用计数失衡问题（对象被提前释放后 autorelease 池二次释放导致崩溃），v1.1.1–1.1.2 的闪退彻底解决
- **QQ 自带大表情也能带文字** — 输入框打字后点自带黄色大表情发送，文字自动并进同一条消息（此前只有收藏表情包支持）
- **新增发送轻提示** — 文字并入成功时屏幕顶部闪现「✓ 文字已随表情发出」，自动消失；自己手机上刚发出的消息因 QQ 本地回显不显示文字时，提示可确认文字已发出
- **防误发保护** — 正常发完文字消息后（输入框已清空）再单发表情，不会把之前的文字带出去
- **发送窗口收紧** — 文字快照有效窗口从 10 分钟收紧到 5 分钟，更精准
