# 常驻后台（com.wacljcr.keepalive）

### 1.0.0 · 2026-11-08

**首发版本：让选定的 app 退到后台保持常驻，重新打开直接回到上次界面。**

微信、QQ、闲鱼、淘宝、京东、抖音、小红书、支付宝、微博等 app 退到后台经常被系统杀掉，重新打开只能冷启动（比如微信看到地球标）、再等界面刷新。本插件让勾选的 app 退到后台后保持常驻，过很久再打开直接回到上次的界面。

- **三层保活**：
  - **音频保活（辅助）** — 进后台播放一段静音音频（音量 0），让 app 处于「正在播放媒体」状态，多数一键清理后台插件会跳过正在播放媒体的 app，所以清不掉它；回前台自动停止，听不到、不耗电
  - **SpringBoard 侧拦截（核心）** — 清理插件（KillBackground13 / KillYourApps / QuitAll / PowerSwitch 等）和 App Switcher 手动划掉，都是在 SpringBoard 里直接调终止 API 杀 app 的；本插件在 SpringBoard 侧 hook 这个终止入口，对勾选保护的 app 直接拦下——一键清理、手动划掉都清不掉它
  - **jetsam 提优先级（防系统内存杀手）** — 进后台把进程优先级抬到前台级别，系统内存杀手优先杀别的低优先级进程，它不再被误杀
- **每个 app 单独开关** — 设置 → 常驻后台 → 要常驻的 app，可多选；也可用「选择要管理的 App」勾选任意已安装 app，与预置功能完全一致
- **总开关可整体关闭** — 关闭后停止音频保活、SpringBoard 不再拦截、优先级自动降回后台默认，系统恢复对 app 的正常管理
- **安全门控** — 注入所有进程但按勾选门控：未勾选管理 / 系统进程完全不受影响
- **设置入口** — 设置 → 常驻后台；面板含使用说明与「联系作者」
- **「联系作者」** — 点击自动复制 QQ 号到剪贴板，再跳转 QQ 加好友界面（号已填好）；QQ 未安装时弹窗提示「QQ 号已复制」，方便手动添加。QQ 号二进制混淆，strings 扫不到明文
- **「使用说明」** — 改为独立子项：面板只显示「使用说明」入口，点击进入子页面才看到逐开关的用途说明（总开关 / 音频保活 / 阻止终止 / 要常驻的 app / 选择 App / 联系作者），不再直接展开在面板上

> 支持 iOS 15.0 – 16.6 的 rootless 越狱（Relaxin / RootHide / Dopamine），依赖 mobilesubstrate 或 ellekit、preferenceloader。
