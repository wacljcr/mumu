# 随机时间打开app

在设定时间段的随机时刻自动打开所选 App，并可打开指定 URL 直达目标页面（如钉钉打卡）。

---

## 功能

- **时间段**：添加多个开始-结束时间段，到点随机挑一个时刻触发
- **生效日**：每天 / 每周指定星期 / 排除某天，非开启日绝不触发
- **App**：从全部已安装 App 中多选，到点依次全部打开
- **打开 URL**：可添加多个 URL（如钉钉打卡链接），在打开 App 后依次打开，直接落到目标页面；也可只配 URL
- **重复打开**：每个时间段内按设定间隔重复触发
- **设置面板**：全量 App 列表带图标、已选置顶、搜索；立即测试、诊断日志一键复制

---

支持 iOS 15.0+ rootless 越狱（Relaxin / RootHide / Dopamine），依赖 mobilesubstrate 或 ellekit、preferenceloader，Sileo 安装后注销生效。
