# 重启/注销（控制中心顶部按钮）

控制中心右上角电量文字上方的电源按钮，点击/长按弹出菜单并真正执行。

---

## 功能

- **注销 / 重启 / 关机** — 电源菜单三档，点击即执行
- **随控制中心显隐** — 下拉出现、收起消失
- **查看诊断** — 菜单内一键导出日志，不依赖设置面板
- **功能开关** — 设置面板可单独开关每一项

---

支持 iOS 14.0+ rootless 越狱（Relaxin / RootHide / Dopamine），依赖 mobilesubstrate 或 ellekit、preferenceloader，Sileo 安装后注销生效。
