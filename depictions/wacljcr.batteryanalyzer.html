# 电池耗电分析

这个插件是干什么的

注入 SpringBoard，持续统计每个 App 的前台/后台运行时长与电量变化，估算各 App 的耗电占比；同时记录电量历史曲线、充电/放电统计、硬件状态（电流/温度/循环次数）与蜂窝信号强度。

主要功能

  • App 耗电：各 App 的耗电占比排行（估算值），按权重分摊显示
  • Tweak 耗电：各 Tweak 的宿主进程实时 CPU% 与耗电潜力分级（低/中/高）
  • 省电诊断：待机漏电测试、省电建议
  • 硬件充电：实时充放电电流（mA）、温度、电池循环次数、电压
  • 电量历史：24 小时电量趋势曲线、本次充电/放电统计
  • 信号强度：蜂窝信号格数分级（信号弱时提示对电量的影响）

使用方法

1. 安装后进入 设置 → 电池耗电分析 打开面板；

2. 顶部 Tab 切换：App 耗电 / Tweak 耗电 / 省电诊断 / 硬件充电；

3. 面板底部查看电量 24 小时趋势与本次耗电统计；

4. 需要联系作者时点击底部「联系作者」，自动复制 QQ 号。

重要说明（诚实标注）

  • 耗电为估算值：基于 App 运行时长与电量变化的推算，不是仪器级精确测量，仅供参考；
  • 单 Tweak 无法实测：所有 Tweak 注入 SpringBoard 共享进程，iOS 无 per-dylib CPU 统计，只能展示宿主进程真实 CPU% 与耗电潜力分级（潜力 = 可能耗电，非实测）；
  • 信号强度为格数分级：iOS 16 未暴露 dBm 精确值，显示为格数分级参考，非精确 dBm。
