键盘下方状态

v1.3.8

系统键盘底栏加功能按钮（全选/剪切/粘贴/光标移动/剪贴板历史/快捷短语/收起键盘）+ 可选状态条。rootless 适配，逐功能可关，安全不崩。

  • 当前版本：1.3.8
  • 更新日期：2026-10-27
  • 开发者：wacljcr

更新记录

1.3.8 · 2026-10-24

  • 新增「文字版 / 图版」模式切换：设置 →「文字版样式」开关。关 = 原来的 SF 图标；开 = 按钮直接显示中文词（全选 / 剪切 / 复制 / 粘贴 / 粘贴板 / 短语 / 左移 / 右移 / 键盘 / 全删 / 启动 / AI / 文言文 / 切换）。图版放不下时，工具栏支持左右滑动
  • 新增「复制」按钮：与剪切 / 粘贴并列，一键复制选中文字（默认开，设置里可单独关）

1.3.7 · 2026-10-10

  • 快捷短语支持批量导入：短语编辑页（键盘点「语」按钮进入）右上角新增「批量」按钮 → 弹出多行文本框，自动填入当前剪贴板内容；确认后按换行分隔一次性导入，自动忽略空行、跳过重复项。另有「覆盖原有短语」开关，关（默认）为追加、开为清空后导入

1.3.6 · 2026-10-07

  • 修复「全删」清不掉候选字（打中真因）：改用 UITextInput 合规的 setMarkedText:@"" + unmarkText，并直接清键盘实例 UIKeyboardImpl 的组合态，清正文前后各清一遍，候选条随正文一起消失
  • 修复「快捷短语」删了又出现（打中真因）：根因是读侧 KSCopyPref 文件缺键不回退 CFPreferences，短语只落进 CFPreferences 时读侧无视它 → 回退默认。现在读侧缺键时回退 CFPreferences，写读两路一致，删空即永久生效

1.3.5 · 2026-10-07

  • 文言文按钮改为本地库一键转换（不联网、不依赖 AI）

1.3.4 · 2026-10-07

  • 新增「文言文」按钮

1.3.3 · 2026-09-29

  • 智能隐藏：输入验证码、密码、纯数字/电话键盘，以及游戏自绘键盘（隐藏输入框）的场景下，工具栏自动不显示；正常打字时照常出现。设置里可关

1.3.0 · 2026-09-28

  • 新增可选只读状态条：时间 / 电量 / 剪贴板预览 / 网络（WiFi / 蜂窝），约 1 秒刷新一次
  • 全部逻辑包在 @try/@catch，任一动作异常都不影响宿主 App；总开关 + 每个功能独立开关，出问题关总开关即恢复原生键盘
  • 只注入普通 App，明确排除 SpringBoard 与 Preferences（设置）
