超级截图

v8.0.20

截完不用再打开别的 App

框选 → 识别 → 翻译 → 打码 → 复制，全在同一个浮层里做完。

怎么呼出

  • 控制中心 — 点模块里的闪电图标
  • 双指上滑 — 任意界面，两根手指往上滑
  • 悬浮球 — 常驻屏幕边缘，点一下直接截
  • URL 指令 — cjt://jb 局部 · cjt://zc 正常 · cjt://ct 长截图 · cjt://pf 拼接，也能挂进快捷指令

截图与编辑

  • 局部截图 — 拖框选区域，四边还能再拉准；工具栏贴在选区外面，不会被截进图里
  • 长截图 — 自动滚动，驱动任意 App 逐屏滚完再精确拼接，中途可停；也能手动点「下一屏」
  • 图片拼接 — 复刻 Picsew 的缝线式拼接，多选相册照片，单张可旋转、翻转、裁剪、排序
  • 画图标注 — 画笔、马克笔、橡皮、矩形、箭头、文字；马赛克和高亮都是拖矩形圈选，只处理圈中区域
  • 打码脱敏 — 像素马赛克、高斯模糊，可手涂，也能自动认出手机号与身份证

识别与翻译

  • OCR 文字识别 — 默认设备端识别，免费、离线、自动判断语种，中英日韩俄法都认；结果按阅读顺序重排，可复制全文。也能切多模态大模型或百度 PaddleOCR
  • 翻译 — 系统自带翻译离线可用，不填任何密钥、不开 VPN 也能翻；也能换成百度翻译（填 APP ID / 密钥）。另有「译文本」，直接把粘贴的文字送翻译，完全跳过图片识别

输出与效率

  • 一键复制 — 点「完成」自动进剪贴板，画完的图不会白画
  • 贴图 — 把截图钉在屏幕最上层，边看边操作
  • 快捷启动 — 秒开微信 / QQ / 闲鱼，截图自动躺进输入框
  • 套手机壳 — 含中框与刘海，出图更像效果图
  • 其他 — 保存到专属相册、系统分享、导出 PDF、压缩、取色（HEX）、旋转、识码、问 AI、截图历史、一键备份恢复

兼容与说明

  • iOS 14 – 17 · rootless（Dopamine / Relaxin / RootHide）
  • 不需要激活码，也不需要 UDID，装好就是全功能
  • 设置面板最底部有「使用方法」，手机上就能翻完整教程
  • 仅限个人学习使用；其他系统或越狱环境未做适配，异常请自行排查

更新记录

8.0.20 · 2026-10-31

8.0.19 的画图核心 + 修黑屏 + 把录制手势加回来。 本版没有新增功能大类，主要把上一轮实验版搞坏的图像管线修回来，并把之前丢掉的录制手势重新做进去。

  • 修复画图黑屏 — 之前的实验版重写了截图/图像管线，在 SpringBoard 侧先铺黑底，导致画图与编辑预览黑掉、显示不全；本版退回 8.0.19 的干净抓屏与合成逻辑，画图显示恢复正常
  • 重新加入「录制手势触发」 — 设置里可录一笔自定义手势来触发截图，入口有三处：设置面板按钮 / 长按悬浮球 0.6 秒 / 悬浮球菜单；还没录模板时，双指上滑自动兜底，不会点了没反应
  • 新增一键复制诊断 — 方便反馈问题时一次性复制设备与插件状态

8.0.19 · 2026-10-27

重做后的首发稳定版。 之前 7.x 有一批版本装上去会黑屏 / 循环重启，已全部停止分发；8.0 从原始源码重做，一路修到翻译可用，这版才发出来。

  • 设置面板内置完整说明 — 最底部「关于 → 使用方法（点击查看）」，可滚动、可长按复制
  • 彻底移除设备授权 — 不再需要 UDID、不需要激活码，装好即全功能
  • 取消「工作模式」 — 两种翻译都要先识别文字，没必要把面板分成两套；改为「翻译引擎（系统 / 百度）」与「识别引擎（系统 / 大模型 / PaddleOCR）」两个独立滑动选择，想要什么就选什么
  • 面板重排 — 80 项精简到 67 项，从上往下按「开关 → 翻译 → 识别 → 大模型（可选）→ 截图与工具栏 → …」排列，一路填完就能用
  • 识别语言不再写死 — 之前只加载简体中文与英文模型，截日文 / 韩文 / 繁体 / 俄文会一个字都读不出；现在取系统支持的全部语言并自动检测语种
  • 翻译十几秒的问题 — 翻译前改成走设备端识别（0.2~1 秒、离线），不再先上传图片等大模型推理
  • 画图「完成」没复制成功 — 剪贴板写入改为带回读校验，失败会提示并可重试，且不会关掉你正在画的图
  • 翻译面板与工具栏重叠 — 系统翻译界面改由独立高层浮窗承载，工具栏被完全盖住，关掉翻译也不会回到工具栏
  • 从旧版升级 — 模型库 Key、百度翻译密钥、工具栏排序、翻译 / 识别引擎选择都会自动迁移，历史截图与自定义机框目录也一起搬过去，不用重填
