本项目仅限个人学习使用，仅针对 Relaxin 越狱环境、iOS 16.6.1 进行适配，其他越狱 / 系统版本均未测试。使用产生的各类报错、异常问题，请使用者自行排查解决。功能说明：截图与裁剪（控制中心按钮或手势呼出浮层，拖框选区可拖动 / 缩放微调，支持正常截图与长截图）；长截图提供 2 种采集方式（长截图界面左上角按钮循环切换）：① 自动滚动——注入驱动任意 App 的 UIScrollView 逐屏自动滚动并精确拼接整页长图，可随时点「停止」；② 手动——框好后滑动页面、点「下一屏 ▼」逐屏采集；自动滚动已放开为全 App 注入（不再仅限微信/QQ）；图片拼接编辑器（复刻 Picsew：多张截图缝线式拼接，单张照片可旋转 / 翻转 / 裁剪 / 删除 / 前后移动，裁剪界面内直接带标注工具（小马赛克 / 大马赛克 / 模糊 / 画笔 / 矩形 / 文字 / 撤销 / 完成），支持马赛克（大 / 小）/ 模糊 / 画笔 / 矩形 / 文字标注，结果可保存 / 复制到剪贴板 / 分享，可选机型套壳且套壳更真实）；OCR 文字识别（视觉大模型引擎与百度 PaddleOCR 两种识别源，结果按阅读顺序上→下、同行左→右重排，可复制全文）；翻译（大模型或百度翻译对选中文字翻译，原文 / 译文可分别复制）；画图标注（画笔实线 / 马克笔半透明粗线 / 橡皮，可选颜色与透明度、撤销）；识码（识别二维码 / 条码，结果可复制或用 Safari 打开）；打开豆包（把当前截图带进豆包 App 直接对话提问，图片同时存入剪贴板可长按粘贴，替代原问 AI / 去状态栏按钮）；图像打码（方块像素马赛克 / 高斯模糊两种涂抹脱敏，可手动涂抹或智能识别手机号、身份证自动打码）；取色（吸管点取图中任意颜色并复制 HEX 值）；旋转（90° / 180° 旋转当前图）；图片压缩（一键压缩并提示前后体积）；贴图（把图片作为浮动窗贴到屏幕，可拖动、双指缩放、关闭）；复制 / 保存 / 分享（复制图片或文字到剪贴板；保存到专属相册「超级截图」；系统分享）；导出 PDF（把截图导出为 PDF）；还原（一键还原为编辑前原图）；启动（工具栏「启动」弹层选要秒开的 App，微信 / QQ / 闲鱼 预设或自定义 URL Scheme，秒开并把截图存入剪贴板）；截图历史记录（回看历次截图）；手机壳库（设置开启后正常截图自动套入手机外壳模板，含中框与刘海，套壳渲染更真实）；常驻悬浮球（设置「启用常驻悬浮球」开关：屏幕常驻可拖动悬浮球，点它直接呼出超级截图，替代控制中心按钮；关闭则回到控制中心方式）；URL 指令（cjt://jb 局部截图 / cjt://zc 正常截图 / cjt://ct 长截图 / cjt://pf 拼接，可在 Safari 地址栏或快捷指令「打开 URL」里触发，设置里多选启用）；设置丰富（工具栏自由排序 / 显隐 / 改名 / 换图标 SF Symbol；控制中心图标五选一相机 / 剪刀 / 闪电 / 文档 / 星星；大模型库识别引擎 / 问 AI / 翻译 分别选模型、一键导入预设、连接测试；百度 PaddleOCR 与百度翻译密钥配置；本插件已彻底放开，无需设备授权或解锁码）。

更新记录

8.0.19 · 2026-10-27

这是重新做过的版本，也是第一个发布到源的稳定版。 之前的 7.x 有一批版本装上去会黑屏 / 循环重启，已全部停止分发；8.0 从原始源码重做，一路修到翻译可用，这版才发出来。

  • 包名更名：com.axs.superscreenshot → com.wacljcr.superscreenshot。装过旧包的请先在 Sileo 里卸载旧包再装本版 —— 包名不同不会自动覆盖，两个包会抢同一个 dylib 文件，卸载任意一个都会把文件删掉
  • 升级不丢配置：首次运行会把旧包名下的模型库 Key、百度翻译密钥、工具栏排序、翻译/识别引擎选择自动搬到新域名；历史截图与自定义机框目录也会整体迁移
  • 设置面板内置完整说明：最底部「关于 → 使用方法（点击查看）」，可滚动、可长按复制，涵盖每个按钮干什么、翻译两种引擎怎么选、大模型怎么申请 Key
  • 彻底移除设备授权：不再需要 UDID、不需要激活码，装好即全功能
  • 取消「工作模式」：两种翻译都要先识别文字，没必要把面板分成两套；改为「翻译引擎（系统/百度）」与「识别引擎（系统/大模型/PaddleOCR）」两个独立滑动选择，想要什么就选什么
  • 面板重排：80 项精简到 67 项，从上往下按「开关 → 翻译 → 识别 → 大模型（可选）→ 截图与工具栏 → …」排列，一路填完就能用
  • 识别语言不再写死：之前只加载简体中文与英文模型，截日文/韩文/繁体/俄文会一个字都读不出；现在取系统支持的全部语言并自动检测语种
  • 翻译十几秒的问题：翻译前改成走设备端识别（0.2~1 秒、离线），不再先上传图片等大模型推理
  • 画图「完成」没复制成功：剪贴板写入改为带回读校验，失败会提示并可重试，且不会关掉你正在画的图
  • 翻译面板与工具栏重叠：系统翻译界面改由独立高层浮窗承载，工具栏被完全盖住，关掉翻译也不会回到工具栏

功能一览

  • 截图：控制中心模块 / 双指上滑（任意界面）/ 悬浮球 / URL 指令（cjt://jb 局部、cjt://zc 正常、cjt://ct 长截图、cjt://pf 拼接）
  • 局部截图：拖框选区，可拖动缩放微调；工具栏贴在选区外面，永远不会被截进图
  • 长截图：自动滚动（注入驱动任意 App 的滚动视图逐屏拼接，可随时停）或手动「下一屏」；底部固定输入栏自动只在末尾保留
  • 图片拼接：多选相册图片，缝线式拼接，单张可旋转 / 翻转 / 裁剪 / 删除 / 前后移动
  • OCR：设备端识别（免费离线、自动检测语种）或大模型 / 百度 PaddleOCR；结果按阅读顺序重排，可复制全文
  • 翻译：系统自带翻译（离线、免 Key、免 VPN）或百度翻译（填 APP ID/KEY）；另有一键「译文本」直接翻粘贴的文字，完全跳过识别
  • 画图标注：画笔、马克笔、橡皮、矩形、箭头、文字，马赛克与高亮都是拖矩形圈选（高亮只压暗一次，不会越圈越黑）；点「完成」自动复制
  • 打码脱敏：像素马赛克 / 高斯模糊，可手动涂或智能识别手机号、身份证自动打码
  • 识码：二维码 / 条形码，可复制或用 Safari 打开
  • 问 AI / 豆包：把当前截图发给视觉大模型提问，图片同时进剪贴板
  • 其他：旋转、复制、贴图（钉在屏幕最上层）、保存、分享、导出 PDF、压缩、取色（HEX）、还原、快捷启动（秒开微信/QQ/闲鱼并把图放剪贴板）、截图历史、手机壳套壳、备份恢复
  • 支持：iOS 14 – 17 rootless（Dopamine / Relaxin / RootHide）
