# 锁屏时钟（com.wacljcr.lockscreenclock）

锁屏后时钟显示时分秒并着色

手机锁屏后，系统时钟改为「时:分:秒」实时显示并着色，支持彩虹渐变 / 预设纯色 / 系统色板 / 时分秒双色（时分一色、秒一色，都可自定义）。横屏锁屏时叠全屏大时钟，竖屏不叠加。

怎么用

1. 打开 设置 → 锁屏时钟

2. 开关插件、显示秒、12/24 小时制

3. 选颜色：彩虹渐变 / 预设纯色 / 系统色板 / 时分秒双色

# 锁屏时钟（com.wacljcr.lockscreenclock）

1.0.0-18 · 2026-11-08

首发上源：竖屏时分/秒双色模式。

  • 手机锁屏后，系统时钟改为「时:分:秒」实时显示并着色。
  • 颜色模式：彩虹渐变 / 预设纯色 / 系统色板 / 时分/秒双色（时分一色、秒一色，都可自定义）。
  • 横屏锁屏时叠全屏大时钟（床头钟），竖屏不叠加。
