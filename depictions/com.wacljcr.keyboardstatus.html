键盘下方状态

v1.4.46

在系统键盘下方加一排常用按钮，打字时不用长按、不用来回切 App。全选、剪切、复制、粘贴、清空、撤销、移光标，点一下就完成。

它还能把系统键盘上那个「地球键」藏起来，换成工具栏里一个更顺手的「切换」按钮 —— 地球键在最左下角，最占位置也最容易误触。

工具栏按钮（17 个，每个都能单独关）

  • 全选：选中全部文字；选中的是网址时，再点一下 = 复制 + 跳转
  • 剪切 / 复制 / 粘贴：常规三件套
  • 粘贴板：剪贴板历史，最近复制过的内容都在里面，点一条直接插入
  • 短语：快捷短语，常发的内容一键带上
  • 右移 / 最左 / 最右：移动光标。按住「右移」可连续移动；「最左 / 最右」长按直达文首 / 文末（这两个默认关闭，省格子）
  • 短删：只删拼音，已经上屏的字保留 —— 拼音打错时不用整段删
  • 键盘：收起键盘
  • 全删：清空整个输入框
  • 撤销：撤回刚删掉的内容，可连按逐步往回撤
  • 启动：快捷启动，一键跳到指定 App（跳转地址可自定义）
  • 文言文：选中文字一键转文言，本地离线词库，不联网
  • 切换：切换输入法（就是被藏起来的那个地球键，变成按钮放到工具栏上）

在「按钮排序」里按住右侧 ≡ 上下拖动，就能调成自己的顺序。

按钮图标与文字，全部可以自己换

工具栏上每一个按钮的图标和文字都能改成自己的，一共 17 个（光标左右移分开算）。

  • 换图标：设置 →「按钮图标与文字」→ 点一个按钮 →「从相册选择图标」。选完可拖动、双指缩放，把要用的部分放进中间方框（居中圈选），保存后键盘和设置里的预览同时换图
  • 改文字：同一个列表里点「修改文字」，最多 3 个字。按整字截断，不是限制拼音输入 —— 你想打「zhongguo」再选「中国」，中间打多长都不影响
  • 还原：顶部「全部还原」一次恢复所有按钮；每行右侧的「还原」只恢复这一个。改坏了随时能退回去
  • 立即生效：改完不用注销、不用重启，设置列表里直接显示你改后的文字，预览条同步刷新

隐藏地球键（合并自 HideGlobe，默认开）

系统键盘底栏最左边那个地球图标，用来切换输入法。它位置固定、又紧挨着空格键，中文打字时经常误触。

开启「隐藏地球图标」后，这个键会被整个隐藏、同时禁用点击，底栏因此干净一截。需要切输入法时，用工具栏上的「切换」按钮 —— 功能一模一样，位置更顺手。

这个开关随时可关：关掉后地球键原样回来，下次弹出键盘即恢复。

几个省事的细节

  • 验证码 / 密码自动隐藏：「智能隐藏」默认开启。遇到纯数字键盘、密码框、系统验证码这类不需要编辑的输入场景，工具栏自动不出现，不挡视线
  • 不会在框架应用里误判：闲鱼这类 Flutter 应用、React Native 应用的输入框是 0×0 的隐藏代理框（文字由框架自己绘制，这个框只负责接键盘事件），现在按类名前缀识别，一律不参与「假输入框」判定，工具栏正常显示
  • 长按连点：「右移」按住连续移动，「最左 / 最右」按住直达文首 / 文末，不用一直点
  • 出错不连累宿主 App：全部逻辑带异常兜底，单点失败只跳过该功能，不会让微信、备忘录之类的打字界面崩掉

外观与布局

  • 单排 / 双排：双排时可调两排之间的间距
  • 图标版 / 文字版：文字版直接显示中文词（全选 / 剪切 / 复制 / 粘贴 …），比图标更好认
  • 大小与间距：图标或文字大小、按钮间距都能调，一行放不下时横向滑动，不压字
  • 数值精调：滑块右侧有数值胶囊，点一下弹数字键盘直接输入精确值 —— 手指拖不准的时候尤其好用
  • 位置：左右偏移、上下抬高，配合不同机型调整，避免压到键盘或贴边
  • 实时预览：设置页里有 1:1 的预览条，拖动滑块立刻看到效果，不用来回切 App 试
  • 图标规格统一：所有图标（含相册自定义图、文字按钮）按真实墨迹高度统一标定，不会出现「有的高有的矮、『文』特别大」
  • 四种光标样式：系统默认 / 细竖线 / 横线 / Mac 拼音横线（拼音还没上屏时，在拼音正下方画一条横线，和 macOS 输入法一样）

复制网址之后

三档可选，默认「询问」：

  • 关闭：什么都不做
  • 询问（默认）：浮出一个「跳转网页」按钮，点了才跳；8 秒无操作自动收起，不会把正在打的内容顶掉
  • 直接打开：沿用旧行为，复制完立刻跳

浏览器可自选 Safari、Chrome、Edge、Quark、Alook、Via 等，也可以手动填 bundle ID 或 URL Scheme。另有「选中网址也自动跳」和「跳转时顺便复制网址」两个开关。

复制文件路径之后

复制的是一条文件路径（比如 private/var/mobile/Library/Logs/CrashReporter）时，工具栏会浮出「跳转路径」，点一下直接打开 Filza 的对应目录，不用一层一层翻。

  • 三档可选：关闭 / 询问（默认，浮按钮等你点）/ 直接跳
  • 全选两次也跳：和网址那套一致，连按两次「全选」自动跳，连按不打断
  • 选中就认：不复制、只是选中一段路径文字，也会浮出按钮
  • /private/var 与 /var 自动归一，两种写法都能定位

备份、诊断与反馈

  • 一键备份 / 一键恢复：把按钮顺序、样式、短语等整套设置导出成 .plist，重装或换机后导入即还原；恢复前会校验是不是本插件的备份文件，不对就不动任何设置
  • 诊断信息：出问题时看这里，插件版本、机型、越狱环境、最近的运行日志都在，方便定位
  • 反馈：设置右上角「反馈」一点，自动带上机型、系统版本和诊断信息，复制或直接发邮件给作者

兼容与说明

  • 支持 iOS 15.0 – 16.6 的 rootless 越狱（Dopamine / Relaxin / RootHide），架构 arm64 + arm64e
  • 依赖 mobilesubstrate 或 ellekit、preferenceloader；设置入口：设置 → 键盘下方状态
  • 不注入 SpringBoard：只在 App 的键盘进程里生效，从结构上杜绝「装完黑屏」
  • 空闲不驻留：没有扫描定时器，不用时不耗电；打字时只扫输入框自己的子树
  • 可直接覆盖安装旧版，原有设置（按钮顺序、样式、短语）不会丢
  • Flutter / React Native 应用里工具栏会正常出现，但「全选 / 剪切 / 左右移光标」这类依赖系统选区接口的按钮可能没反应 —— 这些框架自己管理选区。粘贴、收起键盘、短删不受影响
  • 若某个 App 在 Umbra / RootHide 的「隐藏越狱」名单里，该 App 不会加载任何插件（这是越狱层的行为，不是插件问题）。把该 App 的开关关掉、彻底杀掉重开即可
