键盘下方状态

v1.4.43

1.4.43 · 2026-10-27

  • 修复「闲鱼这类 Flutter / React Native 应用里工具栏完全不显示」。这类应用的输入框是 0×0 的隐藏代理框（文字由框架自己绘制，这个框只负责接键盘事件），原来被「智能隐藏」误判成游戏用的假输入框，于是工具栏在创建之前就退出了。现在按类名前缀识别框架，Flutter / RN 一律不参与误判
  • 本次只加了一个判定函数，没有新增任何 hook，钩子集合与 1.4.42 完全一致
  • 详情页补全全部功能说明（含隐藏地球键、智能隐藏、备份恢复、诊断信息）

1.4.42 · 2026-10-26

  • 修复 Mac 拼音横线整条跑偏到字母区外。横线定位改用系统绘制组合态下划线的同一个接口，位置与宽度都精确；并加合理性校验，私有输入框返回的坐标不可信时自动退回兜底算法

1.4.41 · 2026-10-25

  • 修复拼音横线偏长：改用组合态两端光标差值算宽度，避开私有输入框的坐标偏移
  • 修复全选连按两下不跳转：第二下改为复制 + 跳转
  • 修复光标样式选完又跳回「系统」：分段开关改为点完立即落盘

1.4.40 · 2026-10-25

  • 复制网址不再抢着跳，改为浮出「跳转网页」按钮由你决定，8 秒无操作自动收起
  • 老用户的旧开关自动映射成「询问」，原先关掉的保持关闭

1.4.39 · 2026-10-25

  • 修复「用微信输入法打字 → 卡死 → 自动注销」。剪贴板轮询与变化通知都是同步跨进程调用，原先跑在主线程，微信输入法高频改剪贴板时会把主线程压到系统看门狗判死；现已全部搬到后台串行队列
  • 不再注入 SpringBoard / 设置

1.4.38 · 2026-10-25

  • 做减法：移除「应用启动面板」「AI 大模型」「生效（重启桌面）」三块，插件更轻、配置项更少

1.4.37 · 2026-10-25

  • 给系统键盘底栏加一排常用按钮：全选／剪切／复制／粘贴、光标左右移（长按直达文首文末）、短删、全删、撤销、剪贴板历史、快捷短语、收起键盘。每个按钮都能单独开关、自由排序，工具栏支持单排／双排，字号与间距可调
  • 四种光标样式：系统默认／细竖线／横线／Mac 风格拼音横线
  • 复制网址自动用指定浏览器打开（可指定 Safari / Chrome 等）
  • 稳定性加固：设置读取改为一次读全量表（未命中不再有磁盘 IO 与 cfprefsd 同步调用）、面板写盘改后台合并、拖动滑块不再重建整条工具栏、打字时只扫输入框自己的子树
  • 不再注入 SpringBoard：本插件只在 App 的键盘里生效，SpringBoard 完全不加载 —— 从结构上杜绝「装完黑屏」这类风险
  • 包名更名：com.yzdmm.keyboardstatus → com.wacljcr.keyboardstatus。若你装过旧包，请先在 Sileo 卸载旧包再装本版（包名不同不会自动覆盖）
  • 当前版本：1.4.43
  • 更新日期：2026-10-27
  • 开发者：wacljcr
