键盘下方状态

v1.4.43

给系统键盘底栏加一排常用按钮，打字不用再长按选字：全选／剪切／复制／粘贴、光标左右移（长按直达文首、文末）、短删、全删、撤销、剪贴板历史、快捷短语、快捷启动、收起键盘。每个按钮都能单独开关、自由排序，工具栏支持单排／双排，字号与间距可调。另有可选状态条、复制网址自动用指定浏览器打开、四种光标样式（系统／细竖／横线／Mac 拼音横线）、文言文一键转换（离线）。支持 iOS 15.0 – 16.6 的 rootless 越狱（Dopamine／Relaxin／RootHide），逐功能可关，空闲不驻留、不轮询耗电。遇到问题请在「设置 → 键盘下方状态 → 右上角 反馈」点一下，会自动带上手机型号与系统版本。

1.4.43 · 2026-10-27

版本信息

  • 包名 com.wacljcr.keyboardstatus · 版本 1.4.43 · 架构 arm64 + arm64e（rootless，iphoneos-arm64）
  • 支持 iOS 15.0 – 16.6 的 rootless 越狱（Dopamine / Relaxin / RootHide）
  • 依赖 mobilesubstrate 或 ellekit、preferenceloader；装完到「设置 → 键盘下方状态」配置
  • 可直接覆盖安装旧版，原有设置（按钮顺序、样式、短语等）不会丢

插件功能一览

  • 键盘底栏工具栏：在系统键盘下方加一排按钮，打字不用再长按选字。可用按钮包括全选、剪切、复制、粘贴、粘贴板（剪贴板历史）、短语、最左、最右、短删、全删、撤销、收起键盘、快捷启动、文言文、切换输入法
  • 全选更聪明：选中网址后按第二下 = 复制 + 直接跳转；普通文本按第二下 = 复制，不用来回找按钮
  • 光标左右移：「最左 / 最右」把光标移到行首行尾，长按直达文首文末
  • 每个按钮都能单独开关、自由排序：用不到的可以全关，只留你常用的几个
  • 工具栏外观可调：单排 / 双排、图标或文字版、图标与文字大小、按钮间距，一行放不下时横向滚动而不压字
  • 状态条（可选）：时间 / 电量 / 剪贴板预览 / 网络状态
  • 复制网址后三档可选：关闭 / 浮出「跳转网页」按钮让你点（默认）/ 直接用指定浏览器打开，浏览器可自选
  • 四种光标样式：系统默认 / 细竖线 / 横线 / Mac 拼音横线（拼音还没上屏时在拼音正下方画线，和 macOS 输入法一样）
  • 文言文一键转换：本地离线词库，不联网
  • 快捷短语、快捷启动：常发内容与常用 App 一键带上
  • 逐功能可关、空闲不驻留：无扫描定时器，不用时不耗电；全部逻辑带异常兜底，出错不会连累宿主 App
  • 反馈入口：设置面板右上角「反馈」一点即带机型与系统版本，方便定位问题

这一轮修了什么（1.4.37 → 1.4.43）

  • 1.4.43 修复「闲鱼这类 Flutter / React Native 应用里工具栏完全不显示」。这类应用的输入框是 0×0 的隐藏代理框，被「智能隐藏」误判成游戏用的假输入框，于是工具栏在创建之前就退出了。现在按类名前缀识别框架，Flutter / RN 一律不参与误判（不新增任何 hook）
  • 1.4.42 修复 Mac 拼音横线整条跑偏到字母区外。横线定位改用系统绘制组合态下划线的同一个接口，位置与宽度都精确；并加合理性校验，私有输入框返回的坐标不可信时自动退回兜底算法
  • 1.4.41 三处修复：拼音横线偏长（改用组合态两端光标差值算宽度，避开私有输入框坐标偏移）；全选连按两下不跳转（第二下改为复制 + 跳转）；光标样式选完又跳回「系统」（分段开关改为点完立即落盘）
  • 1.4.40 复制网址不再抢着跳，改为浮出「跳转网页」按钮由你决定，8 秒无操作自动收起；老用户的旧开关自动映射成「询问」
  • 1.4.39 修复「用微信输入法打字 → 卡死 → 自动注销」。剪贴板轮询与变化通知都是同步跨进程调用，原先跑在主线程，微信输入法高频改剪贴板时会把主线程压到系统看门狗判死；现已全部搬到后台串行队列，并且不再注入 SpringBoard / 设置
  • 1.4.38 做减法：移除「应用启动面板」「AI 大模型」「生效（重启桌面）」三块，插件更轻、配置项更少

已知限制

  • Flutter / React Native 应用里工具栏会正常出现，但「全选 / 剪切 / 左右移光标」这类依赖系统选区接口的按钮可能没反应——这些框架自己管理选区。粘贴、收起键盘、短删之类不受影响
  • 若某个 App 在 Umbra / RootHide 的「隐藏越狱」名单里，该 App 不会加载任何插件（这是越狱层的行为，不是插件问题）。把该 App 的开关关掉、彻底杀掉重开即可

1.4.37 · 2026-10-25

  • 给系统键盘底栏加一排常用按钮：全选／剪切／复制／粘贴、光标左右移（长按直达文首文末）、短删、全删、撤销、剪贴板历史、快捷短语、应用启动面板、AI、收起键盘。每个按钮都能单独开关、自由排序，工具栏支持单排／双排，字号与间距可调
  • 四种光标样式：系统默认／细竖线／横线／Mac 风格拼音横线（拼音还没上屏时，在拼音正下方画一条横线，和 macOS 输入法一样）
  • 复制网址自动用指定浏览器打开（可指定 Safari / Chrome 等）
  • 稳定性加固：设置读取改为一次读全量表（未命中不再有磁盘 IO 与 cfprefsd 同步调用）、面板写盘改后台合并、拖动滑块不再重建整条工具栏、打字时只扫输入框自己的子树
  • 不再注入 SpringBoard：本插件只在 App 的键盘里生效，SpringBoard 完全不加载 —— 从结构上杜绝「装完黑屏」这类风险
  • 包名更名：com.yzdmm.keyboardstatus → com.wacljcr.keyboardstatus。若你装过旧包，请先在 Sileo 卸载旧包再装本版（包名不同不会自动覆盖）
